FISTE GUIDEN REV 23

RASK START PÅ WINDOWS:
1. Dobbeltklikk START-HER.bat.
2. Første gang installeres nødvendige Node-pakker automatisk.
3. Appen åpnes på http://localhost:3000

MANUELT:
1. Installer Node.js 20 eller nyere.
2. Kjør: npm install
3. Kjør tester: npm test
4. Start: npm start
5. Åpne: http://localhost:3000

På mobil: åpne den deployede adressen i Chrome og velg «Legg til på startskjerm».
Siste vellykkede analyse kan vises offline; nye live-data krever nett.
NVE HydAPI er valgfritt og aktiveres med miljøvariabelen NVE_API_KEY.
