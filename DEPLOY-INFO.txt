FISTE - HELAUTOMATISK GITHUB + RENDER
====================================

Dobbeltklikk 1-OPPDATER-OG-APNE-FISTE.bat.

Scriptet gjor resten:
- finner/installerer Git ved behov
- leser REV automatisk fra package.json
- henter siste repo
- synkroniserer appfilene
- commit + push til GitHub
- venter pa Render Auto-Deploy
- sjekker /api/health til riktig REV er live
- apner kun Fiste-siden til slutt

Du trenger ikke laste opp via GitHub-nettsiden.
Forste gang pa en ny PC kan Git Credential Manager be om engangsinnlogging.
