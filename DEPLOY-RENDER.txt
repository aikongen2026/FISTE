DEPLOY FISTE GUIDEN REV 23 PÅ RENDER

1. Koble Render Web Service til GitHub-repoet.
2. Runtime: Node.
3. Build command: npm install
4. Start command: npm start
5. Health check path: /api/health
6. Anbefalt: sett MET_USER_AGENT til en nøytral identifikator med prosjektadresse/kontakt.
7. Valgfritt for ferskvanns-live-data: sett NVE_API_KEY til din gratis NVE HydAPI-nøkkel.

Etter deploy skal /api/health blant annet svare med:
{"ok":true,"version":"v11-rev23","revision":"REV 23","marine":true}

Kjør npm test før deploy. REV23-testpakken skal gi 15/15 bestått.
