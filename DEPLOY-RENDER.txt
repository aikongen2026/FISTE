FISTE GUIDEN REV 26 - ENKEL DEPLOY

1) Pakk ut ZIP-filen.
2) I GitHub-repoet FISTE: Add file -> Upload files.
3) Dra ALT INNHOLDET inni den utpakkede mappen inn i GitHub.
4) Commit changes til main.
5) Render deployer normalt automatisk. Ellers: Manual Deploy -> Deploy latest commit.
6) Åpne https://fiste.onrender.com/api/health
   Den skal vise revision: "REV 26".

VIKTIG:
- Det er under 100 filer i pakken, så GitHub web-upload godtar hele pakken i én opplasting.
- Gamle duplikatfiler i repo-roten stopper ikke lenger deploy.
- Serveren bruker bare /public for nettsiden.
